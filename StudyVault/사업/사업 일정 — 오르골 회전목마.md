# 🗓️ 사업 일정 — 오르골 회전목마

#project #business

> **작업 시간**: 주 5회 × 8시간 = 40시간/주
> **목표**: 1월까지 **4단계 (지인 테스트 제작)** 완료

---

## 5월 〔1단계 기획〕 — 맥북만으로 시작 (기획·설계·구매 계획)

> [!note] 현재 상황 (5월 2주)
> 맥북 에어 M1 외 아무것도 없음 — 부품·3D 프린터 모두 미확보.
> 하드웨어 없이 할 수 있는 것에 집중: 시장 조사, 컨셉 확정, Fusion 360 설계, 구매 계획.
> 3D 프린터는 프로젝트용 Ender 3 V3 KE 구매 시 공유 사용.

**1주** 시장 조사 — 국내외 유사 제품(오르골·회전목마·피규어) 가격대·품질·플랫폼 분석, 인스타그램·에치·아이디어스 레퍼런스 수집, 타겟 고객층 정의

**2주** ← 현재 — 제품 사양 확정 + 구매처 조사
— 디지털 오르골 구성 확정: DFPlayer Mini + microSD + 소형 스피커 + Arduino Nano
— DC 모터 규격 확정, 608ZZ 베어링 구매처 선정
— 캐릭터 거치 방식 스케치 (착탈식 vs 고정식)
— 폴리머 클레이 재료·공구 구매처 조사

**3주** Fusion 360 회전 플랫폼 설계
— 프로젝트 5월 4주 Fusion 360 학습과 병행 (같은 소프트웨어·같은 시간)
— 회전 플랫폼 기본 틀 모델링 시작, 608ZZ 베어링 치수 반영

**4주** 설계 완성 + 구매 목록 최종 확정 → 월말 발주
— 회전 플랫폼 STL 완성, 슬라이싱 파일 준비
— 전체 부품 목록 최종 정리 (Ender 3 V3 KE + 전자 부품 + 클레이 재료) → 발주

---

## 6월 〔1단계 제작〕 — 부품·프린터 도착 → 프로토타입 제작

> [!note] 프린터 공유
> Ender 3 V3 KE는 프로젝트·사업 공용. 6월 1주 프로젝트 프린터 세팅 완료 후 사업 플랫폼 출력 병행.

**1주** 부품 도착·검수 + 회전 플랫폼 3D 프린팅 시작
— DFPlayer Mini·Arduino Nano·DC 모터 등 전자 부품 도착 확인
— Ender 3 V3 KE로 회전 플랫폼 PETG 출력 시작 (프로젝트 캘리브레이션 후 바로 적용)
— DFPlayer + Arduino Nano 배선 → 음원 재생 첫 테스트

**2주** 디지털 오르골 + 회전 기믹 제작
— 음원 재생·DC 모터 회전 Arduino Nano로 통합 제어
— 회전 안정성 테스트, 소음·떨림 점검, 속도 조절 구조 개선
— 막히면 → [[사업 부품 목록 BOM — 오르골 회전목마]] 시스템 통합 다이어그램 참조

**3주** 캐릭터 거치 구조 제작 + 클레이 조형 시작
— 피규어 고정 방식 설계·출력 (착탈식 vs 고정식), 폴리머 클레이 1호 캐릭터 조형 시작

**4주** 전체 조립 + 안정성 검증 → **🏁 G1 게이트**
— 디지털 오르골+회전+캐릭터 일체 조립, 2시간+ 구동 테스트, 문제점 수정
— G1 통과 기준 체크: ① 2시간 무중단 ② 소음 ≤ 50dB ③ 고정틀 재사용 구조 확인

---

## 7월 〔2단계〕 — 샘플 제작 (말 프로젝트 부품 대기 기간 집중 활용)

> [!tip] 사업 집중하기 좋은 달
> 프로젝트는 7월 전체가 Fusion 360 모델링 + 코드 완성 작업 (구조 부품은 8월1주 도착 예정).
> 프로젝트 작업과 사업 샘플 제작이 물리적으로 충돌하지 않으므로 병행 최적 구간.

**1주** 샘플 1번 제작 ① — 1호 고정틀 기반 캐릭터 유형 A 선정 (예: 발레리나), 클레이 조형·도색 시작

**2주** 샘플 1번 완성 — 캐릭터 완성·마감, 전체 조립, 완성도 점검, 개선 포인트 기록

**3주** 샘플 2번 제작 — 캐릭터 유형 B 선정 (예: 커플 인형), 조형·도색, 틀 재사용성 검증

**4주** 샘플 2번 완성 + 중간 점검 — 완성도 비교, 고정틀 표준화 항목 정리, 3번 샘플 방향 결정

---

## 8월 〔2단계 마무리 + 3단계 준비〕

> [!note] 말 프로젝트 제작 집중 달 — 사업은 샘플 마무리 + 촬영 준비 위주

**1주** 샘플 3번 제작 — 캐릭터 유형 C (공간/배경 중심 or 기념일 특화), 범용성 증명

**2주** 전체 샘플 품질 검토 + 개선 → **🏁 2단계 완료** — 3개 샘플 비교, 고정틀 최종 완성본 확정, 개선 반영

**3주** 촬영 환경 구성 — 라이트박스·배경지·조명 세팅, 사진 기초 (구도·노출·색온도), 스마트폰 or 카메라 촬영 연습

**4주** 샘플 1차 촬영 + 영상 기록 — 완성품 사진 촬영, 제작 과정 타임랩스/쇼츠용 영상 촬영

---

## 9월 〔3단계〕 — 콘텐츠화 + SNS 업로드 시작

**1주** SNS 채널 개설 및 세팅 — 인스타그램·스레드(or 유튜브쇼츠) 계정 개설, 프로필·바이오 작성, 첫 포스팅 (완성품 소개)

**2주** 완성품 전문 촬영 + 편집 — 3개 샘플 전문 촬영, 영상 편집 (캡컷·릴스), 2차 업로드 (제작 과정 영상)

**3주** 정기 포스팅 루틴 확립 — 주 3회 업로드 계획 수립, 해시태그 전략, 스토리·릴스 활용법 학습, 반응 분석

**4주** 반응 데이터 분석 + 방향 조정 — 어떤 콘텐츠에 반응이 좋은지 분석, 다음 콘텐츠 방향 조정, 팔로워 소통 시작

---

## 10월 〔3단계 계속 + 4단계 준비〕

> [!note] 말 프로젝트 인형 제작 달 — 사업 SNS 운영과 수주 프로세스 설계 병행

**1주** SNS 콘텐츠 지속 운영 — 정기 포스팅 유지, 팔로워 DM 소통, 커버 콘텐츠 (비하인드·제작기) 업로드

**2주** 수주 프로세스 설계 — 의뢰 폼 초안 작성 (캐릭터 정보, 참고 이미지, 납기, 가격), 납품 기간 산정, 가격 정책 초안 (기본가·옵션가)

**3주** 지인 테스트 의뢰자 섭외 — 신뢰할 수 있는 지인 1~2명 섭외, 요청 내용 사전 협의, 제작 일정 조율

**4주** 4단계 제작 계획 수립 — 의뢰 내용 확정, Fusion 360으로 맞춤 틀 수정 설계, 재료 준비

---

## 11월 〔4단계〕 — 지인 테스트 제작

**1주** 테스트 의뢰 1번 착수 — 의뢰 캐릭터 클레이 조형 시작, 맞춤 플랫폼 3D 프린팅, 음원 선정 및 DFPlayer 세팅

**2주** 테스트 의뢰 1번 완성·납품 — 전체 조립·마감, 포장, 납품, 고객 반응 수렴 및 피드백 기록

**3주** 테스트 의뢰 2번 착수 — 2번 의뢰 캐릭터 제작 시작, 1번 피드백 반영 개선 적용

**4주** 테스트 의뢰 2번 완성·납품 — 완성·마감·납품, 피드백 수렴, 양쪽 사례 비교 분석

---

## 12월 〔4단계 마무리 + 5단계 준비〕

**1주** 피드백 분석 + 프로세스 개선 — 두 건의 테스트 피드백 종합, 제작 프로세스 문서화, 병목 구간 개선

**2주** 가격 최종 확정 + 판매 채널 준비 — 원가 계산 (재료비+시간비), 최종 판매가 확정, 스마트스토어 입점 준비 or SNS DM 수주 채널 정비

**3주** 상품 페이지·DM 템플릿 제작 — 상품 소개 문구 작성, 주문 안내 DM 템플릿, Q&A 준비, 후기 콘텐츠 업로드

**4주** 5단계 오픈 최종 점검 — 전체 프로세스 리허설, 재료 재고 확인, 오픈 시기 확정

---

## 1월 〔4단계 완료 선언 + 5단계 직전〕

**1주** 지인 테스트 결과 콘텐츠화 — 후기 공개 포스팅 (지인 동의 후), 비포/애프터 콘텐츠, 신뢰 구축 콘텐츠 연속 업로드

**2주** 포트폴리오 정리 — 1~4단계 전 과정 사진·영상 아카이브, 브랜드 스토리 콘텐츠 제작

**3주** 최종 오픈 준비 완성 — 스마트스토어 상품 등록 or SNS 판매 공지 준비, 말을 탄 여인 프로젝트 마무리와 병행

**4주** **🏁 4단계 완료 선언 → 5단계 오픈 준비 완성** — 회고·개선사항 정리, 다음 제품 라인업 검토, 충분한 휴식

## 🚦 단계 게이트 기준 (Stage Gate Criteria)

> 각 단계 완료 선언 전 아래 기준을 체크. 미충족 항목은 보완 후 다음 단계 진입.

| 게이트 | 단계 전환 | 통과 기준 | 미달 시 |
|--------|---------|---------|---------|
| **G1** | 1단계 완료 → 2단계 진입 | ① 디지털 오르골+회전+캐릭터 일체 2시간 구동 무중단 ② 소음 ≤ 50dB ③ 고정틀 재사용 가능 구조 확인 | 6월 4주 보완 or 7월 1주로 이월 |
| **G2** | 2단계 완료 → 3단계 진입 | ① 샘플 3개 완성 ② 틀 재사용 시간 절감 ≥ 30% ③ 개선 포인트 문서화 | 8월 2주 추가 개선 |
| **G3** | 3단계 완료 → 4단계 진입 | ① SNS 팔로워 200명 이상 ② 저장률 ≥ 5% 게시물 1개 이상 ③ 수주 프로세스 문서화 완료 | 11월까지 콘텐츠 보강 후 재평가 |
| **G4** | 4단계 완료 → 5단계 오픈 | ① 지인 테스트 2건 완료 ② 만족도 ≥ 4.5/5 ③ 원가·납기·SOP 문서 완성 | 1월 추가 개선 후 재확인 |
