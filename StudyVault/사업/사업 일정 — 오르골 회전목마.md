# 🗓️ 사업 일정 — 오르골 회전목마

#project #business

> **작업 시간**: 주 3회 × 8시간 = 26시간/주

---

## 5월 〔R&D〕 — 맥북만으로 시작 (기획·설계·구매 계획)

> [!note] 현재 상황 (5월 2주)
> 맥북 에어 M1 외 아무것도 없음 — 부품·3D 프린터 모두 미확보.
> 하드웨어 없이 할 수 있는 것에 집중: 시장 조사, 컨셉 확정, Fusion 360 설계.
> 3D 프린터는 프로젝트용 Ender 3 V3 KE 공유 사용 예정.

**1주** 시장 조사 — 국내외 유사 제품(오르골·회전목마·피규어) 가격대·품질·플랫폼 분석, 인스타그램·에치·아이디어스 레퍼런스 수집, 타겟 고객층 정의

**2주** ← 현재 — 제품 사양 확정 + 구매처 조사
— 디지털 오르골 구성 확정: DFPlayer Mini + microSD + 소형 스피커 + Arduino Nano
— DC 모터 규격, 608ZZ 베어링 구매처 선정
— 캐릭터 거치 방식 스케치, 폴리머 클레이 재료·공구 구매처 조사

**3주** Fusion 360 표준 베이스 설계
— 프로젝트 Fusion 360 학습과 병행 (같은 소프트웨어·같은 시간)
— 회전 플랫폼 기본 틀 모델링, 608ZZ 베어링 치수 반영

**4주** STL 완성 + 전체 부품 목록 최종 정리 → 월말 발주
— 회전 플랫폼 STL·슬라이싱 파일 준비
— Ender 3 V3 KE + 전자 부품 + 클레이 재료 발주

---

## 6월 〔R&D〕 — 부품·프린터 도착 → 프로토타입 제작

> [!note] 프린터 공유 — Ender 3 V3 KE 프로젝트·사업 공용

**1주** 부품 도착·검수 + 회전 플랫폼 3D 프린팅 시작
— DFPlayer Mini·Arduino Nano·DC 모터 등 전자 부품 도착 확인
— Ender 3로 회전 플랫폼 PETG 출력 (프로젝트 캘리브레이션 후 바로 적용)
— DFPlayer + Arduino Nano 배선 → 음원 재생 첫 테스트

**2주** 디지털 오르골 + 회전 기믹 조립
— 음원 재생·DC 모터 회전 Arduino Nano로 통합 제어
— 회전 안정성 테스트, 소음·떨림 점검, 속도 조절 구조 개선

**3주** 캐릭터 거치 구조 + 클레이 조형 시작
— 피규어 고정 방식 설계·출력 (착탈식 vs 고정식)
— 폴리머 클레이 1호 캐릭터 조형 시작

**4주** 프로토타입 1호 조립 완성
— 디지털 오르골+회전+캐릭터 일체 조립, 구동 테스트
— 문제점 기록 → 7월 개선 반영

---

## 7월 〔R&D 완성〕 — 표준 베이스 확정

> [!tip] 사업 집중 최적 구간
> 프로젝트는 7월 전체가 Fusion 360 모델링·코드 완성 작업 → 물리적 충돌 없음.

**1주** 프로토타입 개선 ① — 6월 문제점 수정, 구조 보강, 소음 대책 적용

**2주** 프로토타입 개선 ② + 반복 생산 테스트
— 동일 틀로 2번째 제작, 시간 절감 여부 확인 (목표: 첫 번째 대비 ≥ 30% 단축)

**3주** 표준 베이스 최종 확정
— 베이스 모듈 치수·재료 확정, Fusion 360 파일 최종 버전 저장
— 고장 취약점 1차 목록 작성

**4주** R&D 완료 선언 → KC 인증 준비 착수
— 표준 베이스 설계 문서화 (치수·재료·조립 순서)
— KC 인증 기관 조사, 전기용품 안전인증 요건 파악

---

## 8월 〔KC 인증 및 안전 검증〕

> [!note] KC 인증은 전기용품안전관리법 대상 — LiPo 배터리·DC 어댑터 포함 제품은 KC 인증 필요

**1주** KC 인증 기관 접촉 + 서류 준비
— 인증 기관 선정, 제품 구성 문서 제출 (회로도, BOM, 사양서)
— 안전 요건 항목 체크: 배터리 보호, 과전류, 절연

**2주** 안전 검증 실측
— 과방전 테스트 (TP4056 보호 회로 동작 확인), 연속 구동 발열 측정
— 포장 낙하 테스트 (배송 중 파손 시뮬레이션)

**3주** 인증 신청 + 제품 제출

**4주** 인증 진행 중 — 피드백 대응 + 보완

---

## 9월 〔숙련도 및 마케팅〕 — 제작 속도 훈련 + SNS 팬덤 형성

**1주** 숙련도 훈련 시작 — 표준 베이스 기준 반복 제작, 1개당 제작 타임로그 기록 시작

**2주** SNS 채널 개설 + 제작 과정 공유
— 인스타그램 계정 개설, 프로필·바이오 작성
— 제작 과정 타임랩스·쇼츠 첫 업로드

**3주** 고장 취약점 보강
— 7월 목록 기반 반복 구동 내구성 테스트, 취약 파츠 보강 설계

**4주** SNS 정기 포스팅 루틴 확립 — 주 3회 업로드, 해시태그 전략, 반응 분석

---

## 10월 〔숙련도 완성 + 사전 예약 오픈〕

> [!note] 말 프로젝트 인형 제작 달 — 클레이 조형 경험 사업과 직접 연계

**1주** 제작 숙련도 목표 달성 확인 — 1개당 제작 시간 ≤ 20h 달성 여부 체크, 미달 시 공정 단축 포인트 분석

**2주** 가격 정책 확정 — 원가 계산 (재료비+시간비), 판매가 확정, 주문 안내 DM 템플릿 작성

**3주** 사전 예약 오픈 — 11월 판매분 4개 사전 예약 SNS 공지, 주문 접수

**4주** 예약 고객 응대 + 재료 준비 — 주문 내용 확인, 맞춤 캐릭터 사전 협의, 재료 발주

---

## 11월 〔런칭〕 — 첫 수익 창출

**1주** 예약 1·2번 착수 — 캐릭터 클레이 조형 시작, 맞춤 플랫폼 3D 프린팅, 음원 선정·DFPlayer 세팅

**2주** 예약 1번 완성·납품 — 전체 조립·마감·포장·배송, 고객 피드백 수렴

**3주** 예약 2번 완성·납품 + 예약 3·4번 착수

**4주** 예약 3·4번 완성·납품 → **🏁 11월 목표: 4개 배송 완료**

---

## 12월 〔런칭 계속〕 — 수익 목표 달성

**1주** 12월 주문 접수 + 착수 — SNS 후기 콘텐츠 업로드, 추가 주문 받기

**2주** 제작·납품 계속

**3주** 제작·납품 계속

**4주** **🏁 2026 마무리** — 12월 추가 제작·납품 완료, 11~12월 누적 수익 집계, 개선사항 정리, 2027 계획 메모

## 🚦 단계 게이트 기준 (Stage Gate Criteria)

> 각 단계 완료 선언 전 아래 기준을 체크. 미충족 항목은 보완 후 다음 단계 진입.

| 게이트    | 단계 전환       | 통과 기준                                                           | 미달 시              |
| ------ | ----------- | --------------------------------------------------------------- | ----------------- |
| **G1** | R&D → KC 인증 | ① 표준 베이스로 2번째 제작 시간 1번 대비 ≥ 30% 단축 ② 설계 문서화 완료 ③ KC 인증 요건 파악 완료 | 7월 내 보완 후 8월 진입   |
| **G2** | KC 인증 → 숙련도 | ① KC 인증 신청 완료 ② 안전 검증 (배터리·발열) 통과                               | 8월 내 보완           |
| **G3** | 숙련도 → 런칭    | ① 1개당 제작 시간 ≤ 20h ② 사전 예약 4건 완료 ③ SNS 팬덤 형성 (팔로워 100명+)         | 예약 달성 시까지 마케팅 강화  |
| **G4** | 런칭 목표 달성    | ① 4개 배송 완료 ② 순수익 ≥ ₩49만 (돔 포함 기준 ₩12만×4)                   | 12월 말 미달 시 1월로 이월 |
