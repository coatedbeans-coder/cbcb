## 🔌 시스템 통합 다이어그램

```
[USB-C 충전 포트]
        │
  [TP4056 충전 모듈]
        │
  [LiPo 3.7V 500mAh]
        │
  [토글 스위치]
        │
  ┌─────┴──────────────────┐
  │                        │
[Arduino Nano]       [DC 모터 3~6V]
  │  UART                  │
[DFPlayer Mini]     [608ZZ 베어링 + 중심축]
  │                        │
[스피커 8Ω]         [회전 플랫폼 (3D 프린팅)]
                            │
                   [캐릭터 피규어 거치]
```

> [!note] 인터페이스 요약
> - **전기**: LiPo → TP4056 → Arduino Nano + DC 모터 공통 전원
> - **제어**: Arduino Nano UART → DFPlayer Mini (음원 재생 명령)
> - **기계**: DC 모터 축 → 기어 or 직결 → 608ZZ 베어링 → 회전 플랫폼
> - **음향**: DFPlayer Mini 출력 → 8Ω 스피커 (5V 허용 출력 범위 내)

## ⚡ 전력 예산 (제품 1개 기준)

| 구성요소 | 소비 전류 (typ) | 소비 전류 (최대) |
|---------|--------------|----------------|
| Arduino Nano (동작 시) | ~15mA | ~40mA |
| DFPlayer Mini (재생 시) | ~20mA | ~40mA |
| 소형 스피커 8Ω @3.7V | ~100mA | ~200mA |
| DC 모터 3~6V (무부하) | ~80mA | ~250mA (부하 시) |
| **합계** | **~215mA** | **~530mA** |

> LiPo 500mAh 기준: 정상 사용 시 **약 2.3시간** 연속 재생 → NFR-B (무선 ≥ 2시간) 충족 ✅  
> 부하 최대 시: **약 0.9시간** → 회전 감속 기어 사용으로 모터 전류 감소 권장
