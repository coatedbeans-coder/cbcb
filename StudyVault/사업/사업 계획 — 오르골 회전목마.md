| 고객 니즈 | 기술 사양 | 목표값 |

## 사업 개요

| 항목 | 내용 |
|------|------|
| **제품** | 오르골 + 회전 기믹 + 수제 캐릭터 피규어 일체형 작품 |
| **핵심 가치** | 메카트로닉스 기술 × 수공예 캐릭터 조형의 결합 |

| **제작 시간** | 주 5회 × 8시간 = **40시간/주** |

## 제품 컨셉

```
[디지털 오르골 (DFPlayer Mini + 스피커)]
        │  Arduino Nano로 동기화 제어
  [소형 DC 모터 → 회전 플랫폼 — 3D 프린팅 틀]
        │
  [수제 캐릭터 피규어 거치]
        │
  [배경·조명 연출 (선택)]
```

- **오르골**: DFPlayer Mini + microSD (MP3 음원) + 소형 스피커, Arduino Nano로 회전과 동기화 제어 / LiPo 내장 배터리로 무선 운용
- **회전 틀**: Fusion 360 설계 → Ender 3 V3 KE 3D 프린팅
- **캐릭터**: 폴리머 클레이 수제 조형 (말을 탄 여인 기술 활용)
- **고정틀**: 반복 생산 가능한 표준화된 틀 + 캐릭터만 교체

## 단계별 로드맵

| 단계 | 목표 | 예상 시기 |
|------|------|-----------|
| **1단계** 프로토타입 제작 | 메커니즘 안정성 검증, 오르골+회전+캐릭터 거치 완성 | 5~6월 |
| **2단계** 샘플 제작 (2~3개) | 고정틀 완성도 확립, 캐릭터 유형 다양화, 범용성 증명 | 7~8월 |
| **3단계** 콘텐츠화 | 제작 과정 영상/사진 기록, 완성품 촬영, SNS 업로드 시작 | 8~10월 |
| **4단계** 지인 테스트 제작 (1~2건) | 실제 고객 요청 프로세스 검증, 숨은 문제 사전 제거 | 11~1월 |
| **5단계** 맞춤 제작 오픈 | 스마트스토어 또는 SNS DM 수주, 고정틀 방식 운영 | 1월 이후 |
| **6단계** DIY 키트 개발 | 누적 경험 기반 키트 난이도·설명서 설계 | 추후 |
| **7단계** 온라인 강의 | 팔로워·후기·브랜드 인지도 확보 후 진입 | 추후 |
| **옵션** 워크숍 | 5~6단계 사이 언제든 추가 가능 | 유동 |

## 📈 단계별 KPI

| 단계 | 핵심 KPI | 목표값 | 측정 시점 |
|------|---------|--------|---------|
| 1단계 (프로토타입) | 프로토타입 완성 + 오르골+회전+캐릭터 일체 구동 | 6월 말 완료 | 6월 4주 |

| 3단계 (콘텐츠) | SNS 팔로워 + 게시물 저장률 | 팔로워 200명 이상, 저장률 ≥ 5% | 10월 말 |
| 4단계 (테스트) | 지인 테스트 만족도 + 피드백 활용률 | 만족도 ≥ 4.5/5, 피드백 개선 ≥ 3건 반영 | 1월 말 |
| 5단계 준비 | 원가·납기·프로세스 문서화 완료 | 표준 제작 SOP 1개 이상 | 1월 말 |
