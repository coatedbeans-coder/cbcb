# 🗓️ 사업 일정 — 커스텀 오토마타

#project #business

> **작업 시간**: 주 3회 × 8시간 = 26시간/주

---

## 5월 〔R&D〕 — 맥북만으로 시작 (기획·설계·구매 계획)

> [!note] 현재 상황 (5월 2주)
> 맥북 에어 M1 외 아무것도 없음 — 부품·3D 프린터 모두 미확보.
> 하드웨어 없이 할 수 있는 것에 집중: 시장 조사, 컨셉 확정, Fusion 360 기구 설계.
> 3D 프린터는 프로젝트용 Ender 3 V3 KE 공유 사용 예정.

**1주** 시장 조사 — 국내외 유사 오토마타 제품 가격대·품질·플랫폼 분석, 트위터/X·인스타그램·아이디어스 레퍼런스 수집, 오타쿠 타겟 구매 패턴 조사

**2주** ← 현재 — 제품 라인업 확정 + 기구 방식 선정
— **라인업 확정**: 오타쿠 라인 (1인 악기·독서 / 2인 자전거·왈츠) + 반려인 라인 (햄스터·고양이·강아지)
— 캠·팔로워 기구 방식 확정 (캠 형태: 편심 원형 vs 하트 캠 등)
— R&D 순서 확정: 디제잉 햄스터 → 고양이 스케이트보드 360스핀 → 강아지 레몬 → 악기 연주 1인 → 2인 기구
— 구매처 조사: 5mm 스테인리스 샤프트, 625ZZ 베어링, M3 볼트·너트

**3주** Fusion 360 기구 설계 시작
— 프로젝트 Fusion 360 학습과 병행 (같은 소프트웨어·같은 시간)
— 캠 형태 모델링, 팔로워·링크 구조 설계, Motion Study로 동작 검증

**4주** STL 완성 + 전체 부품 목록 최종 정리 → 월말 발주
— 하우징·캠·팔로워·크랭크 STL·슬라이싱 파일 준비
— Ender 3 V3 KE + PETG·PLA+ 필라멘트 + 기구 부품 발주

---

## 6월 〔R&D〕 — 부품·프린터 도착 → 프로토타입 제작

> [!note] 프린터 공유 — Ender 3 V3 KE 프로젝트·사업 공용

**1주** 부품 도착·검수 + 하우징 3D 프린팅 시작
— PETG로 캠 하우징·팔로워 가이드 출력 (프로젝트 캘리브레이션 후 바로 적용)
— 샤프트·베어링·볼트 등 기구 부품 도착 확인

**2주** 캠·링크 기구 조립 + 첫 동작 테스트
— 캠 샤프트 조립, 크랭크 연결, 팔로워 동작 확인
— 걸림·유격·소음 점검, 캠 형태·팔로워 형상 개선 설계

**3주** 캐릭터 마운트 구조 설계 + PLA+ 캐릭터 출력
— 기구 상단 캐릭터 연결부 설계·출력
— PLA+ 1호 테스트 캐릭터 출력 + 도색 첫 시도

**4주** 프로토타입 1호 조립 완성
— 하우징+기구+캐릭터 일체 조립, 크랭크 동작 테스트
— 문제점 기록 → 7월 개선 반영

---

## 7월 〔R&D 완성〕 — 표준 기구틀 확정

> [!tip] 사업 집중 최적 구간
> 프로젝트는 7월 전체가 Fusion 360 모델링·코드 완성 작업 → 물리적 충돌 없음.

**1주** 프로토타입 개선 ① — 6월 문제점 수정, 구조 보강, 캠 형상 최적화

**2주** 프로토타입 개선 ② + 반복 생산 테스트
— 동일 틀로 2번째 제작, 시간 절감 여부 확인 (목표: 첫 번째 대비 ≥ 30% 단축)

**3주** 표준 기구틀 최종 확정
— 캠·하우징 치수·재료 확정, Fusion 360 파일 최종 버전 저장
— 고장 취약점 1차 목록 작성

**4주** R&D 완료 선언 → 숙련도 훈련 준비
— 디제잉 햄스터 기구틀 설계 문서화 (치수·재료·조립 순서) — R&D 1번 완료
— 고양이 스케이트보드 360스핀 기구틀 설계 착수 (크랭크 → 회전 플랫폼 직결, 연속 회전)
— SNS 계정 개설 준비, 오타쿠·반려인 채널 분리 전략 기획

---

## 8월 〔숙련도 및 마케팅〕 — 제작 속도 훈련 + SNS 팬덤 형성

**1주** 숙련도 훈련 시작 — 표준 기구틀 기준 반복 제작, 1개당 제작 타임로그 기록 시작

**2주** SNS 채널 개설 + 제작 과정 공유
— 트위터/X·인스타그램 계정 개설, 프로필·바이오 작성
— 기구 동작 영상 첫 업로드 (크랭크 돌리는 장면 중심)

**3주** 고장 취약점 보강
— 7월 목록 기반 반복 구동 내구성 테스트, 취약 파츠 보강 설계

**4주** 캐릭터 도색 퀄리티 표준화
— 도색 공정 단계 정리, 1개당 도색 시간 측정·단축 포인트 파악

---

## 9월 〔숙련도 완성 + SNS 팬덤 강화〕

**1주** 제작 숙련도 목표 점검 — 1개당 제작 시간 ≤ 18h 달성 여부 체크, 미달 시 공정 단축 포인트 분석

**2주** SNS 정기 포스팅 루틴 확립 — 주 3회 업로드, 해시태그 전략 (오타쿠·피규어·오토마타), 반응 분석

**3주** 샘플 촬영 + 포트폴리오 정리 — 라이트박스 제품 사진, 동작 영상 쇼츠, SNS 게시

**4주** 10월 예약 오픈 준비 — 주문 안내 DM 템플릿 작성, 가격 정책 최종 확정, 커미션 접수 폼 준비

---

## 10월 〔사전 예약 오픈〕

> [!note] 말 프로젝트 인형 제작 달 — 클레이 조형 경험 캐릭터 도색에 직접 연계

**1주** 가격 정책 확정 — 원가 계산 (재료비+시간비), 기본/프리미엄 판매가 확정

**2주** 사전 예약 오픈 — 11월 판매분 4~6개 사전 예약 SNS 공지, 주문 접수

**3주** 예약 고객 응대 + 캐릭터 의뢰 협의 — 주문 내용 확인, 맞춤 캐릭터 참고 이미지 수집, 3D 모델링 가능 여부 확인

**4주** 캐릭터 모델링 선착수 + 재료 준비 — 예약 순서대로 캐릭터 Fusion 360 모델링 시작, 필라멘트·도료 추가 발주

---

## 11월 〔런칭〕 — 첫 수익 창출

**1주** 예약 1·2번 착수 — 캐릭터 PLA+ 출력·도색 시작, 기구틀 PETG 출력, 조립

**2주** 예약 1번 완성·납품 — 전체 조립·마감·포장·배송, 고객 피드백 수렴

**3주** 예약 2번 완성·납품 + 예약 3·4번 착수

**4주** 예약 3·4번 완성·납품 → **🏁 11월 목표: 4개 배송 완료**

---

## 12월 〔런칭 계속〕 — 수익 목표 달성

**1주** 12월 주문 접수 + 착수 — SNS 납품 후기 콘텐츠 업로드, 추가 주문 받기

**2주** 제작·납품 계속

**3주** 제작·납품 계속

**4주** **🏁 2026 마무리** — 12월 추가 제작·납품 완료, 11~12월 누적 수익 집계, 개선사항 정리, 2027 계획 메모

## 🚦 단계 게이트 기준 (Stage Gate Criteria)

> 각 단계 완료 선언 전 아래 기준을 체크. 미충족 항목은 보완 후 다음 단계 진입.

| 게이트 | 단계 전환 | 통과 기준 | 미달 시 |
|--------|---------|---------|--------|
| **G1** | R&D → 숙련도 | ① 표준 기구틀로 2번째 제작 시간 1번 대비 ≥ 30% 단축 ② 설계 문서화 완료 ③ 크랭크 연속 100회 무걸림 | 7월 내 보완 후 8월 진입 |
| **G2** | 숙련도 → 사전 예약 | ① 1개당 제작 시간 ≤ 18h ② SNS 팔로워 100명+ | 9월 내 마케팅 강화 |
| **G3** | 사전 예약 → 런칭 | ① 사전 예약 4건 이상 수주 ② 캐릭터 의뢰 협의 완료 | 예약 달성 시까지 SNS 강화 |
| **G4** | 런칭 목표 달성 | ① 4개 배송 완료 ② 순수익 ≥ ₩52만 | 12월 말 미달 시 1월로 이월 |
