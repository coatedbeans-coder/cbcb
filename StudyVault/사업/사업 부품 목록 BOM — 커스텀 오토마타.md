## 🔧 시스템 통합 다이어그램

```
[크랭크 핸들 (수동 입력)]
        │
  [캠 샤프트 — 625ZZ 베어링 × 2 지지]
        │
  ┌─────┴──────────────────────┐
  │                            │
[캠 ① (편심/하트 형상)]     [캠 ② (선택, 2동작 구성 시)]
  │                            │
[팔로워 ①]               [팔로워 ②]
  │                            │
[링크 → 캐릭터 상하 동작]  [링크 → 캐릭터 고개/팔 동작]
        │
  [3D 프린팅 캐릭터 모듈 (PLA+)]
        │
  [PETG 하우징 + 나무 베이스]
```

> [!note] 인터페이스 요약
> - **입력**: 크랭크 핸들 수동 회전 → 캠 샤프트
> - **기구**: 캠 형상에 따라 팔로워 상하 변위 → 링크 → 캐릭터 동작
> - **재료**: PETG (내열·강성 필요 기구부), PLA+ (캐릭터·장식)
> - **전원**: 없음 — 완전 수동. KC 인증 불필요.
