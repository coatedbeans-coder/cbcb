## 5월 (맥북만으로 시작 — 소프트웨어 환경 구축 + 발주 계획)

> [!tip] 학습 원칙 — 경험 선행, 노트는 레퍼런스
> **순서**: 부품을 손에 쥔다 → 조립·분해·움직여본다 → 막히는 순간이 생긴다 → 그 순간 노트를 열어 해결한다
> StudyVault 노트는 커리큘럼이 아닌 **막혔을 때 찾는 레퍼런스** — 순서대로 읽지 않아도 된다.
> 일정은 날짜보다 **완료 기준 충족이 우선** — 필요하면 다음 달로 미룬다.

> [!note] 현재 상황 (5월 2주)
> 맥북 에어 M1 외 아무것도 없음 — 부품·3D 프린터 모두 미확보.
> 이번 달은 소프트웨어 환경으로 먼저 손에 익히고, 월말에 발주·구매 계획 확정.

**2주** ← 현재 — 소프트웨어 환경 세팅 + 가상 첫 실험
— Fusion 360 설치 (무료 Personal 라이선스, M1 네이티브 지원)
— Arduino IDE 설치 + Wokwi 계정 생성 (브라우저 기반 회로 시뮬레이터)
— Wokwi에서 Arduino + 서보 1개 회로를 그리고 delay() 코드로 직접 돌려보기
— 막히면 → [[15.서보 모터]] · [[19.서보 제어 프로그래밍]]

**3주** Wokwi로 갤럽 타이밍 시뮬레이션
— 서보 4개 가상 회로 구성, 갤럽 영상 보면서 타이밍 직접 조정
— delay() → millis() 논블로킹으로 전환 실험 → 막히면 → [[21.타이머와 인터럽트]]
— PCA9685 라이브러리 연동 시뮬레이션 → 막히면 → [[22.I2C와 SPI 통신]]

**4주** Fusion 360 첫 모델링 + 구매 계획 확정
— Fusion 360으로 MG90S 서보 치수 (데이터시트 기준) 입력 → 서보 마운트 단순 파츠 모델링
— 막히면 → Fusion 360 공식 튜토리얼 or StudyVault 노트
— **구매 계획 확정**: Ender 3 V3 KE + 전자 부품 목록 최종 정리 → 월말 발주

  

## 6월 (부품·프린터 도착 → 실물 첫 실험)

> [!note] 5월 Wokwi 시뮬레이션 경험 기반
> 5월에 가상으로 서보 동작·갤럽 타이밍을 실험했으므로, 실물이 도착하는 순간 바로 손에 붙는다.
> 설계 중 막히는 순간마다 → 해당 노트를 찾아보는 방식 유지.

**1주** Ender 3 V3 KE 도착·세팅 + 전자 부품 도착·검수
— 프린터 조립·캘리브레이션, 20mm 큐브 테스트 출력
— 서보·Arduino 실물 배선 → 5월에 Wokwi로 짠 코드를 실물에 그대로 올려보기
— 막히는 부분 → 노트 참조

**2주** 서보 실물 실험 + 갤럽 타이밍 튜닝
— 실물 서보 4개로 갤럽 패턴 조정, Wokwi와 실물의 차이 직접 확인
— GND 공통 배선·노이즈 문제 발생 → [[25.전원 시스템과 배터리]]

**3주** 기획 확정 + Fusion 360 실물 기반 설계
— 서보·베어링 실측 → Fusion 360 파라메트릭 치수 업데이트
— 갤럽 레퍼런스 조사, 작품 전체 구조 스케치, 말·라이더·베이스 크기·무게·중심 확정

**4주** 세부 설계 ① + Motion Study — 말 구동부 설계, Fusion 360 Motion Study로 링크 동작 검증 → **PDR**

  

## 7월 (구조 부품 대기 — 모델링·코드 완성)

> [!note] 배송 일정
> 6월4주 발주 (T-slot·링크 파츠 등 구조 부품) → 약 1달 후 **8월1주 도착** 예정.
> 서보·Arduino는 6월에 이미 실물 실험 완료 → 코드·모델링 완성에 집중.

**1주** 세부 설계 ② + Fusion 360 전체 파츠 모델링 착수
— 인형 구조 설계 (구체관절 위치, 탑승 자세, 활 겨누는 팔, 곡궁)
— 구조 파츠 (다리 링크·베이스·서보 마운트) 모델링 시작

**2주** Fusion 360 전체 파츠 모델링 완성 — 외형 파츠 (말 몸통·머리·다리) 포함 전부 완성, STL 슬라이싱 파일 준비

**3주** Arduino 코드 완성 + Wokwi 최종 검증 — millis() 기반 갤럽 타이밍, PCA9685 연동, 비상정지 로직 → **CDR**

**4주** 공구 점검 + PETG 구조 파츠 출력 시작 — 작업 공간 정리, Ender 3 캘리브레이션 재확인, 다리 링크·서보 마운트·베이스 PETG 출력

  

## 8월 (말 프레임·구동부·외형 제작)

**1주** 구조 부품 도착·검수 + 말 프레임 제작 — T-slot 절단·조립 (말 몸통 골격), PETG 구조 파츠 체결, 다리 관절 기구부 조립·수동 동작 확인

**2주** 구동부 제작 — 서보 마운트 체결, 전체 다리 연동 서보 구동 테스트, 타이밍 조정 (7월에 작성한 코드 적용)

**3주** 구동부 테스트·수정 + 외형 출력 병행 — 갤럽 동작 반복 테스트, 진동·소음·발열 점검·수정, PLA+ 외형 파츠 출력 시작

**4주** 말 외형 제작 ① + TRR — PLA+ 외형 파츠 출력 완료, T-slot 프레임에 체결 → **TRR**

  

## 9월 (말 외형 완성)

**1주** 말 외형 제작 ② — 나머지 파츠 출력 완료, 후가공 (사포 120→240→400방, 수성 서페이서), 디테일 마감

**2주** 말 외형 마감 — 도색, 질감 표현 (눈·코·입 디테일), 장식 마구 제작

**3주** 말 전체 통합 테스트 — 외형+구동부 결합 후 동작 테스트, 외형 손상 여부 확인, 수정

**4주** 말 후가공 및 완성 — 수정 사항 반영, 마감재 도포, 말 파트 완성 선언

  

## 10월 (인형 제작)

**1주** 인형 제작 ① — 구체관절 헤드 조형 (석분점토 또는 폴리머 클레이), 얼굴 디테일 조각

**2주** 인형 제작 ② — 몸통·팔·다리 구체 제작, 관절 소켓 가공

**3주** 인형 제작 ③ — 전체 관절 조립, 앞으로 숙인 탑승 자세 고정 테스트, 활 겨누는 팔 동작 범위 확인

**4주** 인형 후가공 — 표면 샌딩·도색, 눈 제작(유리눈 또는 아크릴 페인팅), 가발 제작 또는 구매·가공

  

## 11월 (인형+말 결합 + 의상 시작)

**1주** 인형+말 결합 테스트 — 인형 탑승 고정, 무게중심 재확인, 앞으로 숙인 자세에서 구동 시 인형 흔들림 점검

**2주** 의상 디자인 확정 — 말 치수·인형 치수 기반 의상 패턴 설계, 비즈자수 배치 디자인, 원단 선정 및 추가 재료 발주

**3주** 의상 제작 ① — 기본 원단 재단·봉제 (상의 베이스, 스커트 베이스)

**4주** 의상 제작 ② — 비즈자수 작업 시작 (상의 자수 집중)

  

## 12월 (의상 완성)

**1주** 의상 제작 ③ — 비즈자수 작업 계속 (스커트·소매 자수)

**2주** 의상 제작 ④ — 의상 마감 봉제, 전체 자수 완성, 인형에 착장 테스트

**3주** 소품 제작 — 두파타, 장신구, 마구 장식 등 소품 완성, 곡궁 제작 및 인형 손 고정

**4주** 분장 및 착장 완성 — 인형 메이크업 페인팅, 의상·소품 최종 착장, 전체 비주얼 확인

  

## 1월 (최종 통합 및 마감)

**1주** 최종 통합 테스트 ① — 인형+의상+말+구동부 완전 결합 상태로 동작 테스트, 의상 걸림·손상 여부 확인

**2주** 최종 통합 테스트 ② 및 튜닝 — 동작 속도·타이밍 미세 조정, 소음 저감, 진동 완충 처리

**3주** 문서 정리 및 평가 — 제작 과정 기록 정리, 설계도 최종본 저장, 잘된 점·아쉬운 점 평가 작성

**4주** 재료 정리 + 향후 계획 수립 + 휴식 — 잔여 재료 정리·보관, 다음 프로젝트 아이디어 메모, 충분한 휴식
