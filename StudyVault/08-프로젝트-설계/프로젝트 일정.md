## 5월 (부품 먼저 쥐기 — 몸으로 시작)

> [!tip] 학습 원칙 — 경험 선행, 노트는 레퍼런스
> **순서**: 부품을 손에 쥔다 → 조립·분해·움직여본다 → 막히는 순간이 생긴다 → 그 순간 노트를 열어 해결한다
> StudyVault 노트는 커리큘럼이 아닌 **막혔을 때 찾는 레퍼런스** — 순서대로 읽지 않아도 된다.
> 일정은 날짜보다 **완료 기준 충족이 우선** — 필요하면 다음 달로 미룬다.

**1주** 즉시 발주 + 작업 환경 세팅
— 국내 익일~3일 배송 부품 즉시 발주: Arduino Uno, MG90S ×2, PCA9685, 브레드보드, 점프선, 624ZZ 베어링 ×4, M4 볼트·너트 세트
— Ender 3 V3 KE 캘리브레이션 + 20mm 큐브 테스트 출력
— 공구 점검, 작업 공간 정리

**2주** 서보 직접 배선 → 손으로 돌려보기
— 배선도 없이 일단 연결해본다 → 안 되면 이유를 추측한다
— delay() 코드로 서보를 먼저 움직인다 → 왜 끊기는지 몸으로 느낀다
— **막히는 순간마다** 노트를 열어 해결: [[15.서보 모터]] · [[19.서보 제어 프로그래밍]] · [[21.타이머와 인터럽트]]
— PCA9685 I2C 배선 시도 → **막히면** → [[22.I2C와 SPI 통신]]

**3주** MG90S 2개로 갤럽 타이밍 직접 실험
— 갤럽 영상을 보면서 앞다리·뒷다리 교차 타이밍을 코드로 직접 조정
— millis() 논블로킹 방식으로 전환 → 안 되면 → [[21.타이머와 인터럽트]]
— GND 공통 배선 후 노이즈·리셋 문제 발생 → [[25.전원 시스템과 배터리]]
— 기구학이 궁금해지는 순간 → [[4.4절 링크장치]] · [[7.힘과 토크]]

**4주** 실물 치수 기반 Fusion 360 모델링 시작
— 손에 든 서보·베어링·볼트를 버니어 캘리퍼스로 실측 → 파라메트릭 치수로 입력
— 서보 마운트 단순 파츠 설계·출력 (추상적 도면이 아닌 실물 기반)
— Fusion 360 조작이 막히면 → 공식 튜토리얼 or StudyVault Fusion 360 노트 참조

  

## 6월 (기획 및 설계)

> [!note] 5월 실험 경험 기반 설계
> 5월에 서보 동작·갤럽 타이밍을 직접 실험했으므로, 설계 결정이 추상적 이론이 아닌 실물 경험에서 나온다.
> 설계 중 막히는 순간마다 → 해당 노트를 찾아보는 방식 유지.

**1주** 기획 확정 — 갤럽 운동 레퍼런스 조사, 작품 전체 구조 스케치, 말·라이더·베이스 크기·무게·중심 최종 확정 (5월 실험 결과 반영)

**2주** 세부 설계 ① — 말 구동부 설계 (관절 수, 모터 배치, 프레임 재질 결정)

**3주** 세부 설계 ② — 인형 구조 설계 (구체관절 위치, 크기 비례, 앞으로 숙인 탑승 자세 고정 방식, 활 겨누는 팔 자세 설계, 곡궁 설계 포함)

**4주** Fusion 360 시뮬레이션 + 발주 시작 — 갤럽 메커니즘 Motion Study (링크 동작 검증·간섭 체크·무게중심 검토), 설계 문제점 도출 및 수정, 부품·재료 목록 최종 확정 후 발주

  

## 7월 (부품 대기 기간 — 모델링·코드 선행 작업)

> [!note] 배송 일정
> 6월4주 발주 (T-slot·링크 파츠 등 구조 부품) → 약 1달 후 **7월4주 도착** 예정.
> 서보·Arduino 등 기본 전자 부품은 5월에 이미 확보·실험 완료 → 코드·모델링 선행 작업에 집중.
> 막히는 개념이 생기면 해당 노트를 찾아보는 방식 유지.

**1주** Fusion 360 전체 파츠 모델링 완성 — 구조 파츠 (다리 링크·베이스·서보 마운트) + 외형 파츠 (말 몸통·머리·다리) 전부 최종 완성, STL 슬라이싱 파일 준비

**2주** Arduino 코드 사전 작성 — millis() 기반 갤럽 서보 타이밍, PCA9685 라이브러리 연동, 비상정지 로직 구현 (하드웨어 없이 Wokwi 시뮬레이터로 검증)

**3주** 코드 검증 + 작업 환경 세팅 — 갤럽 패턴 시뮬레이션 최종 확인, 공구 점검, 작업 공간 정리, 3D 프린터 테스트 출력 준비

**4주** 부품 도착·검수 + 3D 프린팅 시작 — 입고 확인, 부족 재료 추가 발주, Ender 3 V3 KE 캘리브레이션, 구조 파츠 PETG 출력 시작 (다리 링크·서보 마운트·베이스)

  

## 8월 (말 프레임·구동부·외형 제작)

**1주** 말 프레임 제작 — T-slot 절단·조립 (말 몸통 골격), 출력 완료된 PETG 구조 파츠 체결, 다리 관절 기구부 조립·수동 동작 확인

**2주** 구동부 제작 — 서보 마운트 체결, 전체 다리 연동 서보 구동 테스트, 타이밍 조정 (7월에 작성한 코드 적용)

**3주** 구동부 테스트·수정 + 외형 출력 병행 — 갤럽 동작 반복 테스트, 진동·소음·발열 점검·수정, PLA+ 외형 파츠 Ender 3 V3 KE 출력 시작

**4주** 말 외형 제작 ① — PLA+ 외형 파츠 출력 완료, T-slot 프레임에 체결

  

## 9월 (말 외형 완성)

**1주** 말 외형 제작 ② — 나머지 파츠 출력 완료, 후가공 (사포 120→240→400방, 수성 서페이서), 디테일 마감

**2주** 말 외형 마감 — 도색, 질감 표현 (눈·코·입 디테일), 장식 마구 제작

**3주** 말 전체 통합 테스트 — 외형+구동부 결합 후 동작 테스트, 외형 손상 여부 확인, 수정

**4주** 말 후가공 및 완성 — 수정 사항 반영, 마감재 도포, 말 파트 완성 선언

  

## 10월 (인형 제작)

**1주** 인형 제작 ① — 구체관절 헤드 조형 (석분점토 또는 폴리머 클레이), 얼굴 디테일 조각

**2주** 인형 제작 ② — 몸통·팔·다리 구체 제작, 관절 소켓 가공

**3주** 인형 제작 ③ — 전체 관절 조립, 앞으로 숙인 탑승 자세 고정 테스트, 활 겨누는 팔 동작 범위 확인

**4주** 인형 후가공 — 표면 샌딩·도색, 눈 제작(유리눈 또는 아크릴 페인팅), 가발 제작 또는 구매·가공

  

## 11월 (인형+말 결합 + 의상 시작)

**1주** 인형+말 결합 테스트 — 인형 탑승 고정, 무게중심 재확인, 앞으로 숙인 자세에서 구동 시 인형 흔들림 점검

**2주** 의상 디자인 확정 — 말 치수·인형 치수 기반 의상 패턴 설계, 비즈자수 배치 디자인, 원단 선정 및 추가 재료 발주

**3주** 의상 제작 ① — 기본 원단 재단·봉제 (상의 베이스, 스커트 베이스)

**4주** 의상 제작 ② — 비즈자수 작업 시작 (상의 자수 집중)

  

## 12월 (의상 완성)

**1주** 의상 제작 ③ — 비즈자수 작업 계속 (스커트·소매 자수)

**2주** 의상 제작 ④ — 의상 마감 봉제, 전체 자수 완성, 인형에 착장 테스트

**3주** 소품 제작 — 두파타, 장신구, 마구 장식 등 소품 완성, 곡궁 제작 및 인형 손 고정

**4주** 분장 및 착장 완성 — 인형 메이크업 페인팅, 의상·소품 최종 착장, 전체 비주얼 확인

  

## 1월 (최종 통합 및 마감)

**1주** 최종 통합 테스트 ① — 인형+의상+말+구동부 완전 결합 상태로 동작 테스트, 의상 걸림·손상 여부 확인

**2주** 최종 통합 테스트 ② 및 튜닝 — 동작 속도·타이밍 미세 조정, 소음 저감, 진동 완충 처리

**3주** 문서 정리 및 평가 — 제작 과정 기록 정리, 설계도 최종본 저장, 잘된 점·아쉬운 점 평가 작성

**4주** 재료 정리 + 향후 계획 수립 + 휴식 — 잔여 재료 정리·보관, 다음 프로젝트 아이디어 메모, 충분한 휴식
